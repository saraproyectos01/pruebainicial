# pruebainicial

Repositorio de prueba inicial conectado a GitHub:
[https://github.com/saraproyectos01/pruebainicial.git](https://github.com/saraproyectos01/pruebainicial.git)

## Script de Push Automático (Método Tanque Anti-Choque)

Ubicación: `.scripts\gitpush.ps1`

### Uso
```powershell
# Push automático estándar
.\.scripts\gitpush.ps1

# Push con mensaje personalizado
.\.scripts\gitpush.ps1 -Mensaje "Descripción de tus cambios"
```
